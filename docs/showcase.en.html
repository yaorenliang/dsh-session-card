Every session in the sidebar is a single title line, so a long list becomes a wall of similar names. This plugin grows the official row into three lines: the title, the last thing you asked, and the agent preset plus whatever is running under this session.

1

Title: exactly as shipped

Rendered by the official component, verbatim. Ellipsis, pin icons, hover actions, the context menu and drag ordering all stay — the card only makes the row taller, it never takes over interaction.

2

Line two: the last thing you asked

Read from the official turnOutline projection: one line, ellipsised, 12px in the tertiary label colour, a step brighter on hover.

3

Line three: which preset, and what is running

The preset chip is the official agent-preset glyph plus the preset id verbatim (ptc, standard) — never translated, never abbreviated. The other two are the official users and layers glyphs with a count. Badges stay put and the row holds 62px, so the sidebar never jumps.

4

Reading the preset costs nothing

The preset already rides in the snapshot the sidebar renders from (projectionValues.agentPreset). The loop that counts running subagents already walks that list, so reading it is one more field on the same pass: no request, no disk read, no extra iteration.
