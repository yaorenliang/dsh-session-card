标题：官方原样

逐字沿用官方渲染。超长省略、置顶图标、hover 操作、右键菜单、拖拽排序全部保留——卡片只是把行撑高，不接管交互。

2

第二行：你最后问的那句话

取自官方 turnOutline 投影，单行省略，12px 灰色；hover 时提亮一档。

3

第三行：预设 + 在跑什么

预设徽标用官方 agent-preset 图标加 ID 原文（ptc、standard），不翻译不缩写。后面两个是官方 users / layers 图标加计数。徽标常驻，行高恒为 62px，侧边栏不会上下跳。

4

零成本读预设

预设来自侧边栏渲染时本来就拿着的那份快照（projectionValues.agentPreset）。统计子智能体那趟循环已经跑过一遍，读它只是同一趟里多取一个字段——不发请求、不读磁盘、不新增循环。

数据不出本机：Host 只开一个只读路由，会话正文不落新日志 结构不认识就不画：DSH 升级改了行 DOM，这一行安静退回官方 归档会话：完全退回官方单行
